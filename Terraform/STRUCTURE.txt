QUICK DEPLOYMENT OPTIONS
================================================================================

Option 1: Using Deploy Script (RECOMMENDED)
    ./deploy.sh full-deploy dev       # Development
    ./deploy.sh full-deploy staging   # Staging
    ./deploy.sh full-deploy prod      # Production

Option 2: Using Makefile
    make dev-init                    # Initialize dev
    make plan ENVIRONMENT=dev        # Plan changes
    make apply ENVIRONMENT=dev       # Apply changes
    make configure-kubectl ENVIRONMENT=dev

Option 3: Manual Terraform
    terraform init
    terraform plan -var-file="environments/dev.tfvars"
    terraform apply

================================================================================
GETTING STARTED - 5 MINUTE GUIDE
================================================================================

1. Install Prerequisites (if needed)
   brew install terraform awscli kubectl

2. Configure AWS Credentials
   aws configure

3. Initialize Development Environment
   make dev-init

4. Plan Deployment
   make plan ENVIRONMENT=dev

5. Review Plan Output

6. Apply Configuration
   make apply ENVIRONMENT=dev

7. Configure kubectl
   make configure-kubectl ENVIRONMENT=dev

8. Verify Cluster
   kubectl get nodes
   kubectl get pods -A

9. View Outputs
   make output ENVIRONMENT=dev

10. Next: Deploy to Staging/Production
